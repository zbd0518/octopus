## 产品核心

**为个人开发者与团队提供一个简单、美观、自托管的 LLM API 中央开关。**

核心体验：把零散在不同平台、不同协议、不同定价的 LLM 能力收拢到一个统一入口，在「爽用 AI」和「控制成本」之间不做取舍。

**目标用户画像：**
- 主力：独立开发者、技术博主、小团队（2-10 人）、AI 副业创业者
- 次级：技术管理者想统一团队 AI API 入口、写自动化脚本的运维

## 用户怎样获得结果

- **用一个 OpenAI 兼容地址接任意 LLM** — 管理面板建渠道和分组 → 拿到 `https://self.host/v1` + API Key → SDK 直调；协议互转由服务端透明处理
- **不看账单就能控住成本** — API Key 配额/RPM/模型白名单 → 告警规则 → 通知 → 没超预期
- **把多个中继平台统一管理** — 绑定 Hub 站点 → 自动同步渠道、套餐、签到 → 一个面板看全局
- **一眼看清用量与健康** — Analytics 面板 + 日志 → 发现谁在调用、走哪个供应商、延迟怎么样 → 按需调权重
- **减少闲置维护精力** — 自动签到、套餐刷新、渠道健康检查、定时报表 → 每周扫一眼就行

## 能力怎样支撑旅程

- **Hub 站点管理** — 绑定上游中继平台 → 多账号、自动同步、自动签到、套餐额度监控与自动创建「Plan」分组渠道
- **渠道与分组（中继核心）** — 5 种负载均衡策略、AI 路由、条件分组 → 覆盖按延迟/成功率/权重/故障转移的精细分流
- **协议转接层** — OpenAI Chat / Responses / Anthropic / Embeddings 互转 → 应用层只改 base URL
- **API Key 治理** — 模型白名单、过期、配额、RPM/TPM/IP 白名单 → 即使分享也有限
- **模型广场与映射** — 模型目录、价格、渠道覆盖、延迟成功率 → 一眼选模型；映射改写规则做全局重命名
- **语义缓存** — embedding 相似度缓存（流式支持 SSE 重放）→ 节省 API 费用
- **通知与告警** — 错误率/费用/额度/下线 → 8 种渠道送达 → 不再漏异常
- **代理池** — 命名代理（直连/系统/代理池/VMess/SS）→ 在受限网络环境中用
- **WebDAV 云备份** — 定时备份、一键恢复 → 配置不丢
- **CLI 导出** — 为 Claude Code / Codex / Gemini CLI / Cherry Studio / Kilo Code 一键生成配置 → 快速迁移

## 用语与下一步读哪

- **渠道（Channel）** = 一个 LLM 供应商配置（Base URL + API Key + 模型映射）
- **分组（Group）** = 渠道集合 + 负载均衡策略；应用拿 API Key 绑到分组
- **Hub（Remote Site）** = 上游中继平台（New-API / One-API 等）的统一管理入口
- **Plan Provider** = 上游套餐供应商（Codex / MiMo / DeepSeek 等）
- **代理池（Pool）** = 命名代理配置池（直连/系统/VMess/SS，支持 OAuth）
