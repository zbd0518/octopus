# 角色与管理员

### 👥 管理员角色

管理 API 和内嵌 Web 管理界面内置三种角色：

- `admin`：完整权限，包括用户管理
- `editor`：可写的运维权限，包括渠道、分组、设置、API Key、日志、告警和 AI 路由
- `viewer`：只读权限

权限校验由服务端执行，服务端会按当前存储的角色判权，而不是只信任 JWT 中的角色声明。

### 🔑 WebAuthn / Passkey 登录

WebAuthn / Passkey 支持通过无密码登录和注册，支持可配置 RP 设置。你可以在设置页的 `WebAuthn / Passkey` 卡片中配置 RP ID、RP 展示名和允许的 Origin。
